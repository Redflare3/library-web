# Dokumentasi Proyek Web Buku

Repositori ini berisi dokumentasi antarmuka dan struktur halaman dari proyek web perpustakaan/buku. Di bawah ini adalah pratinjau tampilan antarmuka untuk setiap halaman dalam versi **Desktop** dan **Mobile**.

---

## 1. Halaman Beranda (`Index.html`)
Halaman utama yang menyambut pengguna, biasanya berisi ringkasan atau navigasi utama ke bagian daftar buku dan fitur lainnya.
